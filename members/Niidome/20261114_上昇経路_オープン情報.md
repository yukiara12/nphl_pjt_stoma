# 基準額が上がる経路：オープン情報での深掘り

作成日: 2026-11-14
担当: Niidome
起点: 2026-11-09 定例。議会の議事録と公開情報で「要望が出て、誰が拾い、どこで発言され、どう承認されたか」を、上がった自治体について追うこと。

## 確かめること

11/9時点の仮説は「要望書がスタートで、誰かが議会で取り上げ、検討・承認を経て上がる」だった。新留の感触は「議会で議論されなくても上がることがある」。このメモは、公開情報だけで経路が見える事例を、次の順で1件ずつ書く。

1. 増額の事実（いつ、いくら）
2. 公開情報に出た起点（要望書、議員の質問、首長の予算説明、見えない）
3. 誰が受け取ったか
4. 議会や会見で何と言われたか
5. どこで予算・実施になったか
6. 公開情報では見えない箇所

件数の検索（503テナント）と、上位自治体の基準額確認は済んでいる。発言の中身は未読のままなので、ここから埋める。

## 先に読めた事例

### 酒田市（未改定が、近隣の増額のあと再要望で追随）

経路が見える範囲が一番広い。訪問候補10自治体ではないが、11/9の「どこで止まり、何で動いたか」に直接答える。

| 時点 | 公開情報で分かること |
| --- | --- |
| 一昨年の陳情 | 市の回答は「他市の状況等を注視しながら、財源も含めて検討する」。ここで止まっている |
| 2025年4月 | 隣接する鶴岡市が基準額を増額。差額は約3,700円（消化器系。鶴岡市の公開基準額は結腸・直腸系で月12,600円の区分がある） |
| 2025年8月20日 | 2度目の陳情。庄内オストメイト家族会が要望書を酒田市健康福祉部長に手渡し。市議の齋藤美昭氏が仲介。コロプラストの市門氏が同行。中身は、品目・呼称の見直し（回腸を新設）、基準額の増額、仮ストーマへの適用 |
| 令和8年4月1日 | 酒田市が実施を告知。消化器系 8,858円→結腸 12,600円・回腸 13,600円、尿路系 11,639円→15,300円。鶴岡市の水準に揃えている |

出典: [日本オストミー協会山形県支部（2025-08-25）](https://cold-moji-2043.catfood.jp/archives/4020)、[酒田市 地域生活支援事業](https://www.city.sakata.lg.jp/kenko/syogaifukushi/chiikishienjigyou.html)、[鶴岡市 日常生活用具](https://www.city.tsuruoka.lg.jp/kenko/shogaifukushi/service/nitijyouseikatuyougu.html)

読み取れること: 要望書はスタートになりうる。1回目は「検討」で止まり、近隣の増額（水平比較）を根拠にした再要望で動いた。拾ったのは担当部長で、議員は質問の場ではなく仲介として出ている。議会の本会議で議論されたかは、この記事と市の告知だけでは分からない。

### 世田谷区（議員質問が2年続き、当局が調査して当初予算に計上）

11/9の「要望が拾われ、議会で発言され、検討のあと上がる」に一番近い。区の公式議事録そのものではなく、質問者のサイトに質疑が再掲されている。

- 上川あや議員が、2023年2月の本会議と2024年3月の予算特別委員会に続き、2025年3月12日に再度質問。30年近く据え置かれたオストメイト装具の基準額を、実勢価格まで上げるよう求めた。
- 障害施策推進課長の答弁: 令和5年10月に一度改定したが、当事者団体から「使用実態を踏まえていない」と意見があった。今年度に利用者アンケートと装具事業者への聞き取りをし、庁内検討のうえ令和7年度当初予算に新基準額を計上。令和7年10月から消化器系 9,010円→12,450円、泌尿器系 11,840円→13,650円。

出典: [上川あや「障害者への日常生活用具給付事業について」（2025-03-12質問）](https://ah-yeah.com/activity/questions/2025/question20250312b/)

読み取れること: 起点は要望書の原本ではなく、議員の継続質問と、その前段にある当事者団体の意見。当局は「検討します」で終わらせず、アンケートと事業者ヒアリングを挟んで予算化した。上げ幅は中央値付近への小幅改定ではなく、実勢を取りにいった大幅改定。

### 深谷市（首長が当初予算の説明で増額を発表）

訪問候補ではない。過去調査で「議会言及のあと増額」に分類した7市の一つ（消化器系 10,000円、尿路系 13,000円、令和7年8月給付分から）。

- 2025年2月12日更新の市長記者会見で、令和7年度当初予算の主要事業として発表されている。
- 市長の説明は「物価高騰で消耗品の負担が増えているので、人工肛門・人工膀胱のストマ装具の補助を増額する」。要望書や議員名は、この会見記録には出てこない。
- 議会側には、改定直前の令和7年3月定例会（2月20日、3月17日）と、その前の令和6年9月定例会（蓄便袋・蓄尿袋）にヒットがある。発言が一般質問なのか、予算説明の確認なのかは未読。

出典: [深谷市 市長記者会見（令和7年2月）](https://www.city.fukaya.saitama.jp/soshiki/hisho/hisho/tanto/sicyo/shityokisyakaikenhappyo/kisyakaikenR6/17937.html)

読み取れること: 公開されている起点は、要望書ではなく首長の予算説明。物価高騰が理由として明示されている。要望が裏であった可能性は、このページからは否定も確認もできない。

### 越谷市（市の改正告知と、市長本人の実績発表）

- 市のページ: 令和7年10月1日から改正。消化器系・尿路系・紙おむつの基準額増額、紙おむつの対象拡大、身体障害者用自転車の追加がセット。
- 市長（福田あきら）の実績ページ（2025年9月30日、最終更新9月16日）でも同じ内容。消化器系 8,858円→9,000円、尿路系 11,639円→12,000円。
- 令和7年9月17日の予算決算常任委員会民生分科会に「ストーマ」2件、3月11日の同分科会に4件のヒットがある。本文は未読。

出典: [越谷市 日常生活用具の給付](https://www.city.koshigaya.saitama.jp/kurashi_shisei/fukushi/syogaisien/seikatuyogu/nitigu.html)、[福田あきら「日常生活用具給付における対象者や支給品目の拡大」](https://akira-fukuda.com/?p=18009)

読み取れること: 上げ幅は中央値のすぐ上で、他の種目と束ねた制度改正として出ている。要望書が起点だったかは、この2ページには書かれていない。

### さいたま市（一度上がったあと、会派が閉会後に追加要望）

訪問候補。令和7年4月改定で消化器系 9,100円、尿路系 12,200円（過去調査）。その改定の起点は、今回の公開検索では特定できていない。

改定のあと、2026年6月3日、公明党さいたま市議団が定例会の閉会後に市長へ緊急要望を出している。中身は日常生活用具の基準額のさらなる引き上げで、ストーマ装具（袋）に加えシールやリムーバーの値上がりに触れている。本会議の質問ではなく、閉会後の会派要望。

出典: [公明党さいたま市議会議員団（2026-06-03）](https://komei-saitamacity.com/news/20260603-2/)

改定前で次に読むべきヒット: 令和6年6月17日 保健福祉委員会、令和6年9月 決算特別委員会（10月1日・3日）、令和6年2月13日 定例会。

## いま共有できること

「要望書 → 議会での発言 → 承認」が、上がった自治体の共通経路だとはまだ言えない。公開情報だけでも、少なくとも次の3つが並ぶ。

| パターン | 見えた事例 | 止まり方 / 動き方 |
| --- | --- | --- |
| 要望書が担当部に渡り、一度止まり、近隣増額を根拠に再要望して追随 | 酒田市 | 1回目は「他市と財源を見て検討」。鶴岡市の増額が再要望の根拠になった |
| 議員の継続質問に対し、当局が実態調査をして当初予算に計上 | 世田谷区 | 一度の改定では当事者団体が納得せず、調査を挟んで大幅改定 |
| 首長が当初予算や制度改正として発表。要望書は公開資料に出ない | 深谷市、越谷市（起点は未確認） | 議会の一般質問が起点かは、発言本文を読むまで保留 |

11/9に新留が言った「議論にならなくても予算の中に入っていることはありそう」は、深谷の会見記録と矛盾しない。一方で世田谷は、議論が予算化の直前まで公開されている。両方がある、が現時点の答え。

オープン情報の限界: 窓口で渡しただけで記録に残らない要望、閉会後のレク、担当課の中での却下は見えない。見えないことを「なかった」とは書かない。
