# **ストーマ調査PJ｜政策変更に関する仮説案**

2026年10月16日

## **1\. 目的**

コロプラスト社が、どの自治体に、どのような働きかけを行えば、ストーマ装具の給付基準額引き上げや関連用品の給付対象範囲拡大につながりやすいかを検討する。

そのため、①自治体ステータス（政策変更の土壌）と②アクション（政策変更に向けた働きかけ）に分けて仮説を構築する。

## **2\. 仮説①：自治体ステータス**

| 仮説 | 必要な情報 |
| ----- | ----- |
| S1. 給付基準額が低く、長期間据え置かれている自治体ほど、見直しの必要性が高い | 現行基準額、改定履歴、最終改定年 |
| S2. 利用者の経済的負担が大きい自治体ほど、見直しの根拠を提示しやすい | 装具価格、自己負担額、給付対象用品 |
| S3. 既に議会や行政で課題が認識されている自治体ほど、政策変更を検討しやすい | 議会質問、行政答弁、要望書 |
| S4. 財政的・行政的な制約が小さい自治体ほど、改定を実施しやすい | 財政状況、給付実績、担当部署 |
| S5. 近隣自治体で改定が進んでいる場合、見直しを検討しやすい | 近隣自治体の基準額、改定履歴 |
| S6. 予算編成や制度見直しの時期にある自治体ほど、働きかけを政策判断に反映しやすい | 予算編成時期、制度見直し予定 |

## **3\. 仮説②：アクション**

| 仮説 | 必要な情報 |
| ----- | ----- |
| A1. 当事者団体による要望が行政の問題認識を促す | 要望書、提出時期、行政回答 |
| A2. 議会での具体的な問題提起が制度見直しを促す | 議会質問、答弁、その後の対応 |
| A3. 装具価格と自己負担額の提示が改定の判断材料となる | 価格資料、利用者負担、行政の判断根拠 |
| A4. 他自治体の改定事例の提示が制度変更を検討する材料となる | 改定事例、改定理由、参考にした自治体 |
| A5. 行政担当部署との協議により、改定の障壁や必要な条件を明確にできる | 協議経緯、予算上の課題、意思決定過程 |

## **4\. 自治体ステータスとアクションを組み合わせた仮説**

**仮説A：給付基準額が長期間据え置かれている自治体**

装具の実購入費と自己負担額を提示し、見直しの必要性を具体的に説明することが有効ではないか。（S1・S2 × A3）

**仮説B：既に議会で関連議論が行われている自治体**

行政答弁から見直しの障壁を把握し、不足している根拠資料を提示することが有効ではないか。（S3 × A3・A5）

**仮説C：近隣自治体で改定が進んでいる自治体**

先行自治体の改定内容と判断理由を比較資料として提示することが有効ではないか。（S5 × A4）

**仮説D：財政的制約が大きい自治体**

対象者数や追加財政負担を推計し、実現可能な改定案を検討することが有効ではないか。（S4 × A3・A5）

## **5\. 既存DBへの情報追加案**

優先的に収集したい情報は以下のとおり。

1. 給付基準額の改定時期・改定前後の金額  
2. ストーマ関連用品の給付対象範囲・変更履歴  
3. 議会質問・行政答弁の内容と時期  
4. 当事者団体の要望内容・行政回答  
5. 改定または見送りの理由  
6. 各情報の出典URL・確認日

既存DBの収録項目を確認し、不足する情報を追加する。GitHubでは自治体コードを共通キーとして情報を統合し、元データと加工データを分けて管理することを提案する。

## **6\. 検証方法**

**PJ1（DB構築）：** 公開情報から自治体の特徴、政策変更の有無、関連するアクションとその時系列を整理する。

**PJ2（自治体ヒアリング）：** 政策変更の契機、意思決定の過程、改定に至った理由・至らなかった理由を確認する。

両者を組み合わせ、自治体の状況に応じた働きかけの方向性を検討する。

なお、給付基準額の引き上げと対象用品の拡大では判断要因が異なる可能性があるため、必要に応じて仮説を分けて検証する。

## **7\. 最終的に示したいこと**

自治体ごとに、①政策変更の必要性、②政策変更の実現可能性、③有効と考えられるアクションを整理し、コロプラスト社が働きかける自治体の優先順位と具体的な対応方針を検討できるようにする。
